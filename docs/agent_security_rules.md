# Agent 专题：安全与采购数据规则

## 什么时候读

涉及认证、权限、采购金额、供应商、报价、审批、LLM、日志、缓存、上传文件或数据库迁移时必读。纯静态样式和不含业务数据的文案修改可以不读。

本文来源是当前 `AGENTS.md`、真实采购模型、风险/审批/审计实现。适用条件：当前演示级采购项目；过期条件：只能由用户批准的更严格安全规范整体替换。第一阶段功能对等与现有真实采购主链使用不同完成门，但共享“不得泄露真实秘密和真实敏感采购数据”的底线。

## 数据分级

| 数据 | 可以进入 LLM | 可以写日志 | 可以入业务库 | 处理方式 |
| --- | --- | --- | --- | --- |
| 密码、Token、Webhook | 否 | 否 | 只存安全凭据系统或 hash | 传引用，不传明文 |
| 供应商银行账户 | 否 | 否 | 确有业务需要才存 | 入库前加密，展示脱敏 |
| 真实原始报价与商业价格 | 否 | 否 | 是 | 只进入受权限控制的真实采购链，确定性解析与计算 |
| 受控/合成报价与采购页面样例 | 是 | 只写脱敏摘要 | 演示 store 可选 | 第一阶段允许复用上游 Prompt、fake page 和 demo store，必须标记非真实数据 |
| 报价 PDF | 否 | 否 | MinIO + Artifact 引用 | 校验权限、类型、大小 |
| 采购总金额 | 否 | 仅审计允许的结构化金额 | 是 | Decimal，不用 float |
| 已脱敏采购说明 | 可选 | 可写脱敏版本 | 是 | LLM 只能提高风险 |
| 页面结构与非敏感标签 | 是 | 必要时 | 按需 | 最小化发送 |
| Task/Approval/Artifact ID | 是 | 是 | 是 | 仍需组织范围校验 |

## 第一阶段功能对等边界

第一阶段允许直接适配 ProcureRPA 的原始文本/page context Prompt、内存 store、fake Redis、模拟 Executor 和 demo model-call 数据，前提是输入只包含受控、合成或已脱敏采购样例，并且输出明确标记为 demo/simulated。它们尚未完成输入最小化、持久化和真实 Skyvern 接链属于第二阶段债务，不阻断语义适配。

以下底线不因阶段放宽：真实密码、Token、Webhook、银行账户、真实未公开报价、真实合同正文和可识别供应商个人信息不得发送给 LLM 或写入 demo store；不得让模拟/LLM 结果触发真实提交、审批、删除、付款或下单。

## 决策边界

| 决策 | 决策者 | LLM 最多能做什么 |
| --- | --- | --- |
| 是否允许访问数据 | 服务端权限规则 | 不参与 |
| 报价字段对应关系 | schema 校验 + 可选 LLM 提取 | 给候选映射 |
| 金额、税、运费和单位换算 | Decimal 确定性函数 | 不参与 |
| 报价是否可比 | 必填字段与业务规则 | 解释缺失原因 |
| 推荐哪家供应商 | 确定性排序/评分 | 生成非决定性说明 |
| 真实采购链风险等级下限 | 当前确定性 `detect_risk()` | 只能提高，不能降低 |
| 第一阶段上游风险演示 | 隔离的 ProcureRPA 形态 detector | 可保留 Stage 2 分类与保守 fallback，但不能驱动真实采购动作 |
| 是否提交、审批、拒绝、删除 | 用户动作 + 服务端状态机 | 不参与 |

## 必须执行的安全指令

| 指令 | 来源/为什么 | 适用条件 | 过期条件 |
| --- | --- | --- | --- |
| JWT 只取身份，角色和可见范围从数据库重新加载 | 用户停用或权限变化应立即生效 | 所有受保护 API | 令牌改为短时且有可靠撤销/版本机制 |
| 查询先限定 organization_id，再限定部门与品类 | 防止跨租户和横向越权 | 采购、审批、审计、文件查询 | 等价 RLS 覆盖并测试 |
| 管理员全组织可见也不能跨 organization | 管理权限不是平台超管权限 | org_admin 请求 | 明确的平台管理员模型上线 |
| 发起人不能审批自己的任务 | 采购职责分离 | approve/reject | 不得过期 |
| approve 不能自动执行；由发起人显式 continue | 保留人对关键动作的控制 | 高风险任务 | 业务明确批准自动继续 |
| 使用数据库锁或唯一约束保护重复决定与重复提交 | HTTP 重试会重复到达 | 状态变化和幂等接口 | 等价事务机制替代 |
| 金额只用 Decimal/string 进出边界 | float 会产生采购金额误差 | 金额解析、比较、JSON | 不得过期 |
| LLM 输出必须经过 schema 与业务校验后才能进入真实业务库 | 模型输出可能缺字段或编造 | 报价提取与字段映射 | 不得过期；第一阶段只进入标记过的 demo store 仍需 schema 校验 |
| 审计失败不得悄悄改变已完成的业务决定 | 避免审计异常造成二次采购动作 | 审计 best-effort 路径 | 事务策略整体重构 |
| 日志只记录安全错误类型，不记录异常中的密钥或响应正文 | SDK 异常可能带请求内容 | 外部服务与 LLM 失败 | 依赖保证结构化安全错误 |
| 上传文件同时校验扩展名、Content-Type、文件头和大小 | 单一字段可伪造 | 报价文件入口 | 文件服务统一接管 |
| 预签名 URL 必须短期生成，数据库只存对象引用 | 长期 URL 会绕过权限 | 文件访问 | 私有代理下载替代 |

## 新报价功能的最小校验顺序

```text
认证用户
  → 组织 / 部门 / 品类权限
  → 请求字段与 Decimal
  → 受控 URL / 文件边界
  → Skyvern 提取
  → schema 与业务完整性
  → 报价入库
  → 确定性比价
  → 脱敏审计
```

顺序来源/为什么：越早拒绝越少产生孤儿 Task 和脏报价；适用条件：创建或导入报价；过期条件：使用事务化工作流后仍需保留等价顺序。

## 测试最低要求

- 权限改动：至少覆盖同组织允许、跨组织拒绝、越部门或品类拒绝。
- 金额改动：至少覆盖 Decimal 精度、零/负数和缺少可比字段。
- 审批改动：至少覆盖禁止自批、重复决定、批准继续、拒绝取消。
- LLM 改动：至少证明真实禁止字段没有进入 prompt，非法输出不能进入真实业务库；第一阶段 demo 用例必须使用合成数据并显示来源标签。
- 文件改动：至少覆盖伪 PDF、超限、越权和存储失败。

以上测试要求来源/为什么：它们直接防止泄密、错账和流程阻断；适用条件：对应代码发生变化；过期条件：同一风险已被更低层的持续门禁完整覆盖。

## 联调时禁止

- 不在聊天、命令输出、截图或提交中粘贴 `.env` 内容。
- 不用真实供应商账号、银行账户或报价做演示样例。
- 不为了调试临时关闭租户过滤、审批或日志脱敏。
- 不把真实 Webhook 当作普通测试字符串。

这些禁令来源/为什么：调试输出同样可能公开；适用条件：本地、CI 和演示环境；过期条件：不得过期。
